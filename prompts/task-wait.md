Ask a concrete blocking question and suspend automatic task continuation until the next user message. The task stays unfinished. Use task_wait only when an unanswered user decision, missing information, or authorization blocks further progress; provide the actual question and its unfinished task ID. This tool shows the question and ends the tool batch when called alone. It is not a way to stop at a milestone, skip work, or wait for another agent. Prefer ask_user for an interactive question when available; its open dialog already holds continuation. An extension report does not count as a user answer.
